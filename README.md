# Characterizing and Mitigating Protocol-Dependent Gene Expression Bias in 3′ and 5′ Single-Cell RNA Sequencing 
This repository contains the code used for data preprocessing, batch correction/ normalization, metric computation, and figure generation for the article: "Characterizing and Mitigating Protocol-Dependent Gene Expression Bias in 3′ and 5′ Single-Cell RNA Sequencing".
